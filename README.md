# Odin Recipes

## Overview
Welcome to my **Odin Recipes**! This project is a simple, multi-page recipe website built as part of **The Odin Project's** Foundations curriculum. The main goal is to apply foundational HTML knowledge to structure a basic website from scratch, featuring an index page that links out to several individual recipe pages.

## Skills Demonstrated
Once completed, this project will demonstrate proficiency in the following areas:
* **HTML5 Boilerplate & Structure:** Setting up standard HTML documents (`<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`).
* **Semantic HTML Elements:** Organizing text and content meaningfully using headings (`<h1>`–`<h6>`), paragraphs (`<p>`), and emphasis tags (`<strong>`, `<em>`).
* **Lists:** Creating unordered lists (`<ul>`) for ingredients and ordered lists (`<ol>`) for step-by-step cooking instructions.
* **Links & Images:** Connecting pages together using relative file paths (`<a>`) and embedding properly sized images with descriptive `alt` attributes (`<img>`).
* **Git & GitHub Workflow:** Initializing a repository, staging changes, writing clear, atomic commit messages, and pushing code to GitHub.
